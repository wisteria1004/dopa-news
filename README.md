# DOPE（旧ドパガキニュース）

縦スクロールでニュースを読む。

縦スクロールで次のニュース、横スクロールでそのニュースの詳細が読める、ショート動画型のニュースサイトです。

- `index.html` だけで動く静的ページです（GitHub Pages で公開）。
- 記事の選定・要約・解説は、AI（Anthropic社のClaude）が出典を確認しながら編集しています。
- 本文は要約と独自の文章で構成し、各記事に出典リンクを付けています。

## 過去号
- 毎日の号は `archive/YYYY-MM-DD/index.html` に保存され、一覧は `archive/` で見られます。
- 号を作ったあと `python3 tools/publish_day.py` を実行すると、その日の号の保存と一覧の更新を行います。号の目録 `archive/days.json` も同時に作り直します。
- 画面上部の日付を押すと「号をえらぶ」パネルが開き、目録から好きな日の号へすぐ移れます（過去号のページからも使えます）。
- 記事の共有リンクは日付付きのページ（例：`archive/2026-11-24/#n03`）を指すので、翌日以降も同じ記事が開きます。

## 共有（リンクカード）
- 記事のリンクボタンは `archive/日付/nXX/`（記事ごとの入口ページ）をコピーする。SNSに貼ると、その記事の見出しと要約が画像付きのカードで出て、開くと記事へ移る。
- 入口ページは `tools/publish_day.py` が全号ぶん毎回作り直す。
- 記事ごとのカード画像 `archive/日付/nXX/card.png` は `tools/card.py` が見出しから自動で作る（記事の色の背景＋黒い見出し、強調語句に白い蛍光ペン）。既にある画像は作り直さない。作れない環境では共通画像を使う。
- トップページのカード画像は `assets/og.png`（1200×630）。元のデザインは `tools/og.html`。サイト名を変えるときは、og.html を直して画像を撮り直し、index.html の og: 系の項目と publish_day.py の `SITE_NAME` を変える。
